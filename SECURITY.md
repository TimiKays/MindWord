# 安全问题反馈

嘿，这里说一下 MindWord 的安全相关事项。

## 发现问题怎么办？

- 直接联系我：timikays@qq.com（备注安全问题）
- 或者在 GitHub Issues 创建私密 Issue
- 看到后会尽快处理，但个人项目响应可能慢点

## 数据边界

- MindWord 采用本地优先设计，未使用云同步时，文档默认保存在当前设备
- 统一账户使用邮箱进行身份识别和登录验证
- 只有使用云同步功能时，相关工作区数据才会传输到 TimiCloud

## 需要注意的

- AI 功能需要你自己配置 API Key，请妥善保管
- 浏览器本地存储有容量限制，重要文档记得备份
- 项目依赖 CDN，如果 CDN 出问题可能影响使用

## 响应时间

个人项目，时间有限，但安全相关问题我会优先处理，一般 3-7 天内会给回复。

## 免责声明

项目按"现状"提供，因使用本项目产生的任何损失，开发者不承担责任。请自行评估风险，重要数据请多重备份。

# Security Issues & Feedback (English)

Hey, here's what you need to know about MindWord security.

## Found a Security Issue?

- Message me directly: timikays@qq.com (mention security issue)
- Or create a private GitHub Issue
- I'll handle it ASAP, but as a personal project, response might be slower

## Data Boundaries

- MindWord is local-first; documents stay on the current device unless cloud sync is used
- The unified account uses an email address for identification and sign-in verification
- Workspace data is sent to TimiCloud only when cloud sync is used

## Things to Note

- AI features require your own API Key - keep it safe
- Browser local storage has limits - backup important documents
- Project relies on CDN - issues might affect functionality

## Response Time

Personal project with limited time, but security issues get priority. Usually respond within 3-7 days.

Project provided "as-is". Developer not liable for any losses from using this project. Please assess risks yourself and backup important data.
